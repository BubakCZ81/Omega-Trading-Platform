Alpaca Market Data · Read Only

Enter your Alpaca API Key ID and Secret Key. Credentials stay in memory unless you explicitly save them; saved credentials are encrypted on this device. Review and confirm each order before submission.

Use credentials from your Alpaca paper or live account. Select the matching environment when creating the keys.

Broker credentials are session-only unless you explicitly save supported credentials.

MetaTrader 5 Market Data and Trading

Connect to the broker account signed in to your local MetaTrader 5 terminal. Omega does not read or save your MT5 password. Manual chart orders require this session to be armed and a confirmed chart preview. Pine strategy orders also require the separate preview opt-in below and confirmation for each order.

Use a 64-bit Python interpreter for which the MetaTrader5 package imports successfully. If the default Python fails, install MetaTrader5 for a supported interpreter and enter py -3.13 (or a quoted full path) above. Keep MT5 open and signed in to your broker. Select its instruments in the chart symbol picker using the MT5: prefix.

    Interactive Brokers · TWS / IB Gateway

    Keep TWS or IB Gateway open and signed in. Enable socket clients in its API settings. Connections stay on this computer; no IBKR password is requested or stored. TWS defaults are paper 7497 and live 7496; IB Gateway defaults are paper 4002 and live 4001. Enter the matching local port and verify the account before connecting.

    Disconnected. Chart orders require real-time bid/ask data from IBKR.

    Automatic IBKR Pine strategy trading is off.

    Chart symbol format: stocks such as AAPL, forex such as EURUSD, and futures as ES 202609@CME (symbol, YYYYMM expiry, exchange). Futures require an exact contract and real-time market-data permissions. Manual and Pine strategy orders show a preview and submit only after confirmation; strategy previews are separately opt-in.

    Quantower Local Feed

    Start a compatible local bridge in Quantower, then connect here. Orders use the selected connected Quantower account.

    Disconnected.

    cTrader · MCP Gateway

    Omega connects only to http://127.0.0.1:9876/mcp/. It maps symbols, details, trend bars, and polled spot quotes for charts; only confirmed chart market orders use place_market_order. Orders go to the account currently active in cTrader, so verify demo/live there before confirming. Other discovered tools are catalog-only. The gateway quote response has no source timestamp.

    Disconnected.

    Register the redirect URL http://localhost/omega/saxo-callback for a Saxo OpenAPI application. Omega uses OAuth PKCE; the App Key and session tokens are kept in memory only.
